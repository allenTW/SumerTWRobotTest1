第十五輪：一個已發布的結論，兩天後被一次查詢推翻

同一輪裡還有 199 個從來沒被看過的合約、一個結構上完美卻量出來是零的候選， 以及一個宣稱 Sharpe 6.45 的標本——它跟我們自己測到輸錢的那條線是同一條。

摘要：這一輪發生了什麼

先看這裡

這一頁是一輪獨立的研究紀錄，不是舊報告的修訂版。依照你 2026-09-21 的指示 「以後報告盡量不要修改舊的，每次產生新的頁面」，舊的那份總覽報告一個字都沒有動； 這一頁裡要更正它的地方，是在這裡寫清楚、然後連回去。

這一輪的主題可以用一句話講完：我們去看了五個以前沒看過的地方，五個都是空的， 但在看的過程中發現舊報告裡有一句話是錯的。 那句錯話的價值比五個空地方加起來還高，所以它放在最前面。

所有英文縮寫、單個字母、希臘字母，在這一頁自己的術語表裡都有白話翻譯； 正文第一次用到時也會就地附註。

一、五件事，照重要性排

★ 1. 一個已經印在報告上的結論，被推翻了

第六輪寫過、而且寫進了總覽報告：幣安上的代幣化股票合約「EQUITY 標籤數量為 0、全部已下市」， 因此「沒有純機械的篩選方法，人工清單無可避免」。 兩天後，一次公開 API 查詢就推翻了它：今天實際是 EQUITY 163 個、TradFi 永續合約 199 個。 詳見下一節，含成因與對舊報告的定位。

2. 一條從來沒人看過的資料軸：199 個 TradFi 永續合約

前十四輪一次都沒把它們當成機會看過——它們只以「把名單弄髒的東西」的身分出現過。 最小下單 $5，所以錢太少在這裡不是障礙（這是很少見的）。 然後一個量測關掉了整個家族：抽樣的 27 個合約裡， 25 個的資金費中位數恰好是 0。見第二節。

3. B1：條件全部滿足，答案是乾淨的零

它滿足這個專案的每一條收案條件，而量出來是 -0.0305%／年、t = -0.138、143 個獨立週觀測。 它失敗的方式是最好的那種：不是「測不出來」，是「這個數就是零」。 見第三節。

★ 4. Sharpe 6.45 的標本——這一段對你最有用

本輪遇到最高的宣稱是 Sharpe 6.45，證據等級只有部落格。 而它宣稱的期間跟我們自己測過的方案一幾乎完全重合，我們的實測是 幣數比 0.9463（輸給純持有）。 差別不在策略，在會計。 第四節把它拆成一份你以後可以直接套用的檢查清單。

5. 還沒被看過的地方，以及兩份實驗規格

最大的未覆蓋區塊是造市／掛 maker 單，而且舊報告否決它的理由可能用錯了門檻。 另有兩份規格：SPEC-1 需要真實下單，是你本人的決定，團隊不會代為執行； SPEC-2 研究員自己建議不要跑，而那個理由本身就是產出。 見第七節與第八節。

二、幣數比這一欄，這一輪是空的——為什麼

這個專案唯一的計分方式是幣數比：同一筆錢、同一段時間，最後手上的 BTC 顆數， 除以什麼都不做、單純每週買進並持有的顆數。 六年 319 週純持有拿到 0.8511 顆，這個成績定義為 1.0000。

這一輪沒有任何一個候選走到可以算幣數比的階段，所以這一頁不提供新的幣數比數字。 原因不是偷懶，是算不出來：幣數比需要一條「真的持有了某個部位、走完一整段時間」的序列， 而本輪的候選全部死在那之前—— 有的是量出來根本沒有可收的東西（沒有部位可模擬）， 有的是成本地板就壓在效應量上（模擬出來必然是負的，而且答案與時間長度無關）， 有的是連能不能開倉都還沒確定（SPEC-1 那道閘門）。

這一頁出現的唯一一個幣數比是 0.9463， 它是引用自舊報告的舊數字（方案一資金費收割）， 用途是當作對照——不是本輪的新成績。

這一頁的術語表（精簡版）

只收這一頁會用到的詞，共 19 條。 舊總覽報告有一份 69 條的完整版，在那邊的術語對照表。 第三欄寫的不是字典定義，是「這一輪為什麼在乎它」。

〔一〕這一頁的記分方式
符號／術語它是什麼（日常語言）這一輪為什麼在乎它
幣數比 這個方案最後拿到的 BTC 顆數 ÷ 什麼都不做、只是每週買進並持有拿到的顆數。 純持有六年是 0.8511 顆，定義為 1.0000。1.0276 就是多拿 2.8%，0.9463 就是少拿 5.4%。這是本專案唯一認可的成績單，本輪沒有產生任何新的幣數比。
獨立觀測數 不是「有幾筆資料」，是「有幾筆互相不重複的資料」。 同一個星期的 21 筆 8 小時資料講的是同一件事，只能算 1 筆。這一頁反覆出現它，因為合約數量多不等於證據多。
t 值 效應量除以它自己的誤差。大致可讀成「這個數看起來不像 0 的程度」。 本專案的門檻是 3.0。|t| 小於 1 幾乎就是「和 0 分不出來」。
sd（標準差） 一串數字上下跳動的幅度。 用來量「兩個應該相等的東西，實際差多少」。差得太小，就連手續費都賺不回來。
bp（基點） 萬分之一。10 bp = 0.10%。 手續費的慣用單位。來回一趟 taker 約 20 bp = 0.20%，這個數字在本頁是好幾個候選的死因。
Sharpe 每承受一單位波動換到多少報酬。越大看起來越好。 它看不出幣變多還變少，而且很容易被「只算其中一條腿」灌水。見第四節。
〔二〕合約與費用
符號／術語它是什麼（日常語言）這一輪為什麼在乎它
永續合約 沒有到期日的期貨。靠一個叫「資金費」的機制把價格黏住現貨。 本頁所有候選都在永續合約上。
資金費（funding） 永續合約多空雙方之間互相支付的費用，通常每 4 或 8 小時結一次。 它是「把幣放著也能收錢」這類策略的收入來源。本輪最大的發現就是：TradFi 永續身上這一項多半是字面上的 0。
carry（持有成本／持有收益） 純粹因為「抱著不動」而自動產生的損益。 如果 carry 是 0，那這個部位就只剩下方向的賭博，不是收租。
TradFi 永續 / TRADIFI_PERPETUAL 幣安上的一類合約，標的不是加密貨幣而是股票、ETF、黃金、原油等傳統資產。contractType 是合約的分類欄位。 今天有 199 個。這個欄位就是本輪找到的那個機械判別式。
underlyingType / EQUITY 另一個分類欄位，標示標的的種類；EQUITY 表示股票。 第六輪的錯誤就發生在這兩個欄位之間——程式查了這一個，卻先被另一個濾掉了。
MIN_NOTIONAL（最小下單金額） 一張單至少要多少錢才能送出去。 TradFi 永續是 $5。對照本專案被規模卡死的那個候選（VRP）要 0.1 BTC ≈ $8,080。
taker / maker taker＝直接吃掉別人的掛單，馬上成交、手續費較貴；maker＝自己掛著等別人來吃，較便宜甚至有回饋。 第十二輪實測嚴格只掛 maker 單、30 分鐘內成交率 97.30%。
〔三〕部位與風險
符號／術語它是什麼（日常語言）這一輪為什麼在乎它
delta 部位對標的漲跌的敏感度。delta = 0 表示漲跌都不影響你。 delta 恆為 0 是本專案收案的硬條件之一，因為目標是多拿幣，不是賭方向。
β（beta） 部位跟大盤（這裡是 BTC）一起動的程度。 β 如果被改變，就等於偷偷改變了你原本的曝險，那不算「加值」。
空 gamma 一種報酬形狀：平時穩定小賺，出大事時一次賠很多，而且賠的上限沒有界線。 本專案把這種形狀列為地雷，因為「回撤不超過 10%」這種約束對它是無效的——它不是慢慢跌，是一次跳空。
槓桿 ETF 耗損 兩倍／三倍槓桿的 ETF 每天重設倍數，長期會因為來回震盪而自己流失價值。 理論上「同時放空一對正反向槓桿 ETF」就能把這個流失收下來。本輪實測了，見第五節。
Multi-Assets Mode（多資產保證金模式） 幣安的一種錢包設定，開了之後可以用手上的 BTC 直接當保證金，不必先換成 USDT。 它是 SPEC-1 要問的唯一問題：如果 TradFi 永續不吃這個模式，那一整族 8 個候選全部作廢。
PASS / FAIL / INDETERMINATE / CONDITIONAL 候選的四種判定：通過／否決／證據不足以判定／有條件成立。 INDETERMINATE 是最容易被誤讀成 FAIL 的一種——它的意思是「還沒有人去量」，不是「量過了不行」。

白話導讀

幣安上有一種合約，標的不是加密貨幣而是股票、黃金、原油那些。第五輪發現這些東西混進了 我們的測試名單裡，第六輪去追原因，然後寫下一句話： 「這些合約早就全部下市了，所以一個機械的篩選方法都做不出來，只能靠人工列清單。」

這句話今天被證明是錯的。那些合約不但還在，而且有 199 個， 還有一個一行就能寫完、零誤判零漏判的篩選方法。

錯在哪裡值得你看一眼，因為這種錯很難防：當時那支程式先做了另一道過濾， 那些合約在被檢查之前就已經被丟掉了。所以程式回報「一個都沒濾掉」是真的， 「數量是 0」也是真的——但從這兩個真話推出來的那句「交易所上沒有這種合約了」是假的。

成因：兩個各自為真的句子，推出一個假的結論

第六輪那支程式先過濾了 contractType == 'PERPETUAL'， 而 TradFi 合約的 contractType 是 TRADIFI_PERPETUAL—— 它們在 EQUITY 這道檢查執行之前，就已經不在集合裡了。

所以：「過濾器一個符號都沒濾掉」是真的（該濾的早就不在了）、 「EQUITY 標籤數量為 0」也是真的（在那個已經被削過的集合裡確實是 0）。 兩句話在它們自己的框內都成立，但由此推出的那句關於交易所的陳述是假的。

這是這一輪最值得留下來的一課：一個數字的真假，和「產生它的那個框有多大」是兩回事。 程式沒有出錯，錯的是把框內的答案當成框外的事實。

實際影響

  • 「人工清單無可避免」現在為假。 contractType == 'TRADIFI_PERPETUAL' 是一個零誤判、零漏判、可即時查詢的判別式。 那份 173 個符號的人工清單，至少在往後的篩選上可以退休。
  • 但只到「往後」為止。歷史上已下市的符號，封存檔裡有沒有保留 contractType 這個欄位， 本輪沒有查，標記為未驗證。人工清單能不能整條退休，取決於這一點。
  • 舊報告的其他結論不受影響。第六輪同時量化過：樣本內是 0 / 2600 席被汙染、 修正後重跑沒有任何結論翻轉。被推翻的是「做不出機械篩選」這個方法論宣稱，不是那些回測數字。 原文仍留在舊報告那一節，沒有刪改。
  • 這條記錄本身列入誠信紀錄。舊報告已經有一節專門列「我們自己做錯過什麼」， 這是又一筆，而且是目前為止間隔最短的一筆——兩天。

白話導讀

上一節找回來的那 199 個合約，前十四輪從來沒有人把它們當成機會評估過。 state 檔全文提到代幣化股票，都只是在講「它們汙染了名單」，沒有一次是在問「它們身上有沒有東西可以拿」。

這句話請看清楚：不是小 carry，是沒有 carry

「平均年化 +13%」這種數字在這些合約上是有的——但它完全不是你抱著就會收到的東西。 中位數是 0，代表超過一半的結算期，帳上一毛錢都沒動； 而全部費用的 56.5%（中位）集中在最極端的那 5% 期數裡。 加密永續的同一個數字是 BTC 33.1%、 ETH 36.5%——分散得多。

最極端的例子是 IWMUSDT： 98.1% 的結算期資金費是 0， 而全部的費用100% 都在最極端 5% 的期數裡。 這不是一個「收益率低」的東西，這是一個平常不存在、偶爾跳一下的東西。

這個結論用一次 API 呼叫就對 199 個合約全部成立，不需要逐一回測。 整個「在 TradFi 永續上收 carry」的家族，到這裡關閉。

四、Sharpe 6.45 的標本——以及你以後可以自己套的檢查法

這一節不是在批評誰。它是把「一個看起來好到不可能的數字」拆開給你看它好在哪裡， 而拆解用的對照組，是本專案自己花了一整輪測出來的同一條線。

白話導讀

這一輪去外面盤點策略時，看到最漂亮的一個宣稱是 Sharpe 6.45。 Sharpe 可以粗略理解成「賺的錢除以過程中的顛簸」，超過 2 就已經很少見，6.45 是天文數字。

然後我們發現一件很剛好的事：它做的就是我們第一輪做過的那件事，連時間段都幾乎一樣。 而我們自己量的結果是——最後手上的幣比什麼都不做還少 5.4%。

差別在哪？不在策略，在會計。那個宣稱只算了收到的資金費，沒有算持有部位本身的漲跌。 資金費是一條幾乎只往上走的線，只看它當然漂亮； 但你要收這筆錢，就必須同時扛著一個會上下跳的部位，而那一腿它沒算。

為什麼「只算一條腿」一定會做出爆表的 Sharpe

資金費的收入曲線近乎單調上升：大多數時候是正的、金額小、幾乎不回頭。 Sharpe 的分母是「顛簸」——一條不顛簸的線，分母接近 0，Sharpe 自然就爆表。

但那條線不是你的損益。要收到這筆錢，你必須同時持有一個會上下跳的部位， 而那個部位的漲跌比資金費大一到兩個量級。 把兩腿合起來算，顛簸馬上回來，Sharpe 就落回地面。

而這正是本專案自己犯過的錯，只是換了一張臉。 舊報告的誠信紀錄裡，口徑偏誤 #1 就是同一件事： 某個方案的 Sharpe 從 3.54 修正到 0.17， 差了 20 倍，而策略一個字都沒改，改的只是算法的口徑。 細節見舊報告〈已修掉的重大缺陷〉。

宣稱 Sharpe 6.45 的那條線，就是本專案花了第一輪、量到幣數比 0.9463 的同一條線。 差別不在策略，在會計。

這是這一輪對你最有實用價值的產出。不需要會寫程式，也不需要看懂回測。 六個問題裡只要有一個問不出答案，那個宣稱就該降級處理。

六個問題裡，第 1 和第 2 可以獨立擋掉絕大多數的誇大宣稱，而且都不需要任何技術能力： 「你這個數字是把所有該算的都算進去了嗎？」「換成幣，最後是變多還是變少？」

本專案自己被這兩題擋下來過至少兩次（口徑偏誤 #1、以及把兩個不同長度的時間窗混在一起算）。 這不是用來懷疑別人的工具，是用來懷疑自己的工具——它對自己人和外人一樣有效。

舊報告那一節點名「唯一值得投資源」1 個（多空籃子）、「第二優先」1 個（VRP）， 其餘 41 個都不建議。43 − 2 = 41 ✓ 自洽；36 個 FAIL ＋ 7 個非 FAIL = 43 ✓。 所以 7 個非 FAIL 裡，恰好 2 個被點名，另外 5 個全部落在那 41 個「不建議」裡面。

結論是：缺的不是 5 個未知的機會，是 5 個「已知理由被卡住」的東西—— 幾乎必然死在硬限制（規模／要開兩個交易所／速度／要寫自動化）而不是死在證據，與 VRP 同一型。 而後續輪次已經獨立關掉其中幾扇門：BTC 借貸（六年 $31.54）、 CTA 趨勢（跨資產中位 alpha +2.4% 對上 BTC 的 14.29% 門檻）、 買別人的市場中性基金（規格上不可執行）。 真正未知的缺口最多剩 1 ~ 2 個槽位。

七、最大的一塊還沒被看過的地方：造市／掛 maker 單這是推論，不是紀錄

白話導讀

「造市」的意思是：不去追價格，而是掛在買賣兩邊等別人來成交，賺中間那個價差。 在交易所的收費結構裡，這種單（maker 單）不但比較便宜，有時候還有回饋。

這一塊十五輪以來沒有任何一輪碰過。而它當初被否決的理由，可能用錯了門檻。

它的狀態在紀錄上就是「還沒有人去量」

舊的派工書列了 6 個「在框架外、而且還沒被證偽」的類別。 十五輪之後，唯一一個沒被任何後續輪次碰過的就是「造市／流動性提供」， 原文的狀態寫的是「期望值未被否證（前次是以門檻駁回）」—— 這在字面上就是 INDETERMINATE 的定義：不是量過了不行，是還沒有人去量。

工作區佐證：maker_review/ 是空目錄； backtest_dca_hedge/makercost/ 是第十二輪的執行成本覆核，不是造市研究。

★ 一個可能的誤用：兩個「門檻」不是同一件事

舊紀錄用「幣安造市商門檻：30 日 1000 BTC」把這一塊駁回了。 但那是「做市商計畫」（Market Maker Program）的申請門檻——那是一個會員資格，不是掛 maker 單的門檻。

任何人都可以掛 maker 單，不需要任何資格，也沒有任何量的下限。 參加做市商計畫是為了拿更好的費率與回饋，跟「能不能用掛單的方式提供流動性」是兩回事。

而且第十二輪已經實測過：嚴格只掛 maker 單、30 分鐘內成交率 97.30%， 且部位大小不是瓶頸。 否決的理由和實際可執行的東西，不是同一件事。這句話值得有人把它拆開重看。

推論 研究員把這一塊標記為「4 個 INDETERMINATE 槽位的最高機率佔用者」， 並明確要求標註：這是推論，不是紀錄。本頁照辦。 本頁沒有宣稱造市可行，只宣稱它還沒有被量過，而且當初的否決理由可能對錯了對象。

其他仍未覆蓋的地方

  • TradFi 永續的微結構／收盤時段效應。 研究員先自己打了預防針：這幾乎一定需要挑「哪幾個小時」這種參數，會直接撞上本專案的收案標準 （零參數）。也就是說，就算去做，做出來的東西大概率不合格。
  • 已下市符號的 contractType 有沒有留在歷史封存檔。 這決定第一節那份 173 個符號的人工清單能不能整條退休， 還是只能在「往後」退休。本輪沒查。

八、兩份實驗規格

SPEC-1：一次點擊可以關掉 8 個候選需要你本人決定

白話導讀

有一族 8 個候選，全部依賴同一個前提：能不能直接用手上的 BTC 當保證金去交易 TradFi 永續 （幣安的「Multi-Assets Mode」）。

如果不能，那要做這些策略就得先把 BTC 換成 USDT——那等於把幣賣掉， 整族 8 個候選當場全部作廢。

而這個問題查文件查不到（下面誠實標註第 5 點會說為什麼），只能實際下一張單試。

SPEC-1 的完整規格

SPEC-2：研究員自己建議不要跑——而那個理由本身就是產出

SPEC-2 原本是「把資金費調查從 27 個擴大到全部 199 個合約」。 研究員自己建議不要做，理由是：

199 個合約不是 199 個獨立觀測。 它們共用同一套結算引擎、同一組夾板參數、同一個利率項設定。 真正獨立的是「契約設計決策」——而那只有一個。 就算用最寬鬆的方式按 underlyingType 切，也只有 7 類。

而 27 個抽樣裡已經有 25 個中位數恰為 0。 擴大到 199 個，增加的是合約數，不是資訊量。

這是本專案核心矛盾在一條全新資料軸上的又一次重現： 換了一個從來沒看過的、199 個合約的資料軸，獨立觀測數還是個位數。 這個專案缺的從來不是資料量，是互相獨立的證據。

九、誠實標註：這一輪的結論有哪些地方站不穩

以下七項是研究員自己揭露的，不是覆核時被抓到的。 按照慣例，這一節不做任何淡化處理。

白話導讀

這一節要講的是「上面那些結論，哪些是硬的、哪些是軟的」。 把它們混在一起講，才是真正的不誠實——所以這裡分開列。

最重要的一句：這一輪大部分的 FAIL，靠的不是「統計上證明它是 0」， 而是「它的規模比手續費還小」。這兩種理由的強度不一樣，不能互相冒充。

先分清楚：這一輪哪些證據是硬的

強證據與弱證據分開列——不要把這兩欄合併成一句樂觀的話

研究員自揭的七項限制

  • 1．TradFi 的歷史極短。最長 9.3 個月、中位數只有 3.4 個月， A3 / A4 的獨立週觀測數只有 5 ~ 12。 這些 FAIL 的信心來自「效應量與成本的量級比」，不來自統計顯著性。 研究員的原話值得抄下來：「正確的反駁不是『t 不顯著』——是『成本地板就在效應量上』。」
  • 2．B1 是本輪唯一有足夠樣本的量測（2,978 期、143 週、跨 2024–2026）， 所以它的 FAIL 紮實。其餘的量測都不到這個等級。
  • 3．槓桿 ETF 那一條只測了 TQQQ / SQQQ 一組，沒測 SOXL/SOXS 等其他組合。 研究員要求照實標明：這一條是用代數關掉的，不是用資料關掉的。
  • 4．文獻只取到摘要層級，沒有一篇取到全文。 與第七輪對 SSRN 6701738 的揭露同一級別。 凡是靠文獻擋掉的候選，其證據強度上限就在這裡。
  • 5．那個 UNKNOWN 是怎麼來的。抓取幣安 FAQ 之後，模型回答「不適用於 TradFi 永續」， 但那是模型從「頁面沒有提到」推論出來的，不是頁面的正面陳述。 研究員拒絕採信，標為 UNKNOWN——這就是 SPEC-1 存在的原因。 這是加分項，不是扣分項
  • 6．本輪所有量測都落在今天這一次抓取，沒有時間戳稽核。 TradFi 合約太新，沒有不可變的歷史封存可以對帳。 因此本輪沒有產生任何乾淨的首次讀取，本頁也不宣稱有。
  • 7．一個確認項：assetIndex 確認 BTCUSD 的 bid/ask buffer = 0.05， 也就是那個 5% 的折價是活的、可驗證的，與舊紀錄一致。這一項是對得上的。

關於覆核程序本身

這一輪沒有走完整的外部覆核流程。研究員依其限制未產出報告檔， 並明確要求協調者不要代寫；協調者沒有代寫。 本頁所依據的複驗，是協調者針對關鍵數字的逐項獨立重算 （重新抓取 905 個符號、重跑集合恆等式、重算資金費統計），結果逐項吻合。

本頁作者另外自行讀過三支腳本，確認了一件事： 資金費的年化是從 fundingTime 差分推出間隔的， 所以本頁的表沒有踩到第二節提到的那個 2 倍低估。

把這一段寫出來，是因為「這一頁的把關程度」本身就是讀者需要知道的資訊。 它比平常的流程短，所以本頁的所有結論都應該按這個折扣來讀。

結論

一段話講完

這一輪去看了五個以前沒看過的地方，五個都是空的。 但在看的過程中，發現舊報告裡有一句話是錯的，而那句錯話的價值比五個空地方加起來還高。

還有一件對你日常有用的事：我們在外面看到一個宣稱「Sharpe 6.45」的策略， 拆開來發現它就是我們自己測過會輸錢的那條線，只是少算了一半的帳。 第四節那六個問題，你以後看到任何策略宣傳都可以照著問。

這一輪確定的事

  • 「人工清單無可避免」是假的。有一個零誤判、零漏判、可即時查詢的機械判別式。 這更正了舊報告的一段話，而舊報告本身一個字都沒有改。
  • TradFi 永續上沒有 carry 可收。不是小，是字面上的 0。 整個家族在一個量測裡關閉，唯一的例外因為沒有對沖腿而不能用。
  • B1 是 0。而且是那種「不會因為多等幾年而翻案」的 0。
  • 199 個合約不是 199 個獨立觀測。 這個專案缺的從來不是資料量，是互相獨立的證據。

這一輪沒有確定的事

  • 幣數比沒有新數字，因為沒有任何候選走到那一步。 本頁不提供任何硬湊出來的幣數比。
  • 造市／掛 maker 單還是沒有被量過，而它當初的否決理由可能對錯了門檻。
  • Multi-Assets Mode 能不能用在 TradFi 永續，仍然是 UNKNOWN。 那需要一張真實的單，而那是你本人的決定。
  • 已下市符號的歷史欄位沒查，所以人工清單只能在「往後」退休。

為什麼這一頁不寫「終局」「結案」這類字眼

研究員拒絕下終局結論，理由不是客氣： 本輪有一個已經發布的結論，在兩天之後被一次 API 查詢推翻， 而推翻它的原因只是「沒有人再去看一次」。

這種事會再發生。所以這一頁的每一個 FAIL，都應該讀成 「以今天能看到的證據，它不成立」，而不是「它永遠不成立」。 差別在於：前者會被寫下來、留著、等著被人回頭查；後者會被歸檔然後遺忘。

這一輪最實際的一句話還是那一句：在目前這個資金規模上， 把錢投進去的那個動作本身，比任何一個聰明的操作都有效。 第二節與第三節只是把另外兩扇門關上而已。
